# DKMS 0.1.6 build, load, and initial mesh smoke

## Build and provenance

Current source commit `86c0023` was staged as flat driver inputs with manifest
`f3857073ff4c96e5147cb3a982f49a01f09e5f9ec25781fb4fb07a22d182a79d`.
The Pi's `6.12.47+rpt-rpi-v8` warning-enabled build passed with five modules
and zero diagnostics. DKMS 0.1.6 then built and installed all five modules.

A controlled USB-unbind/module-reload/USB-rebind loaded the exact installed
0.1.6 modules from `updates/dkms`; all five loaded `srcversion` values and
SHA-256 hashes matched the built artifacts. The recovery harness re-established
both RTL8812AU mesh points and reciprocal HWMP paths in 11 seconds.

The intended antenna-capability correction is observable on both new PHYs:

```
Available Antennas: TX 0 RX 0
```

This replaces the former false `TX 0x3 RX 0x3` selectable-chain advertisement.
The fresh post-reload kernel interval contained no warning, error, or transport
event.


## Open multicast gate: failing

Two independent sender-captured 400-frame probes on channel 1 HT20, with root
`fc:22:1c:30:08:c1` on USB branch `1-1.4` and peer
`fc:22:1c:30:0d:8b` on `1-1.1`, failed the 99% delivery threshold only in the
root-to-peer direction:

| Probe | Root sender / peer receiver | Peer sender / root receiver | Kernel transport events |
| --- | --- | --- | --- |
| `20260812T130846Z` | 400 / 391 (97.75%) | 400 / 400 | 0 |
| `20260812T131151Z` | 400 / 394 (98.50%) | 400 / 400 | 0 |

A separate valid lower-rate diagnostic (`10 × 20` frames at 0.20 seconds,
six-second capture window) delivered 191/200 (95.5%) root-to-peer and 200/200
peer-to-root, again with zero transport event. This rules out the original
20 Hz burst profile as the sole explanation.

Both radios reported 20 dBm on channel 1 under `country DK`; Pi temperature was
74.0°C and `get_throttled=0xe0000` represented historical, not current,
throttle/under-voltage bits. These results are a reproducible directional
delivery failure, but by themselves do not attribute cause to the driver,
adapter, antenna/RF environment, hub branch, or power path. They do prevent
calling the 0.1.6 open group-traffic gate a pass.
